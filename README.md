# md-04 - Exploratory data analysis using visualization & Data organization in spreadsheets

## What's in here

- `live-data-visualisation.qmd` - live coding from lecture (with `-solutions` companion)
- `hw-data-visualisation.qmd` - data visualisation homework (with `-solutions` companion)
- `hw-project-data.qmd` - capstone project data exercise
- `learning-04.qmd` - learning reflection
- `data/`, `figs/`, `img/` - datasets, generated figures, and images

## How to use

1. Clone into Posit Cloud (workspace linked from the course site).
2. Open `md-04.Rproj`.
3. Render `.qmd` files with Quarto.
